# PS4001/PS7001: Next-Generation Sequencing Analysis

Course materials for a project-based course on analyzing next-generation
sequencing (NGS) data: RNA-seq (pseudo-alignment and genome alignment) and
DAP-seq/ChIP-seq. The course was written for the Hellbender HPC cluster at the
University of Missouri.

**Author:** Pierce Taylor

The full course content is still being added (see the open pull request).
