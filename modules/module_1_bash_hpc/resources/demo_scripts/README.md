# Bash demo scripts

Short example scripts used with M1P2 (variables, arguments, conditionals,
loops, functions, file I/O and here-documents).

**Changes:** none to the script contents. `menu.sh` (credited upstream to
LinuxCommand.org) and the `finalGrade.txt`/`gradebook.sh` demo files were
left out.

| Script | Shows |
|---|---|
| `hello.sh` | first script |
| `arguments.sh`, `arguments1.sh` | positional arguments, `$#`, `$@`, `$*` |
| `std-io.sh`, `FileIO.sh`, `hereScript.sh` | input/output, reading files, here-documents |
| `conditional.sh`, `bin/conditional1.sh`, `test-file.sh`, `string-comparison.sh`, `multiway-selection.sh` | `if`/`elif`/`case` and file and string tests |
| `forloop.sh`, `for-countdown.sh`, `while-countdown.sh`, `fizzbuzz.sh` | loops |
| `functions.sh`, `functions1.sh`, `variablesArray.sh` | functions, local/global variables, arrays |
| `systemInfo.sh`, `invoke.sh`, `compile.sh`, `iptables.sh` | larger examples (system report, getopts, compiling) |
