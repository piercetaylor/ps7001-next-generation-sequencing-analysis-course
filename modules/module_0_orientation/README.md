# Module 0: Orientation

Getting started: how the course uses Jupyter on the Hellbender HPC, how to prompt AI tools responsibly, and where to find computing and NGS reference material.

## Learning objectives

- Find the computing resources (Hellbender, conda, R, Python, nf-core) used throughout the course
- Write precise, context-rich prompts for AI assistants and critically evaluate the answers
- Locate background reading and videos on sequencing technologies and experimental design
