### Module Deployments for PS4001/PS7001

## Scripts

There are 8 bash scripts, one for each week. Week one deploys modules 0 and 1 to the student folders. Weeks two through 8 deploy
their own respective weeks. 

## Running deploments

In a fresh terminal run the following commands: 

`cd "$CLASS_DIR"`  (the root of the course directory)

`chmod +X Development/module_deployments/week_1_deploy.sh && bash Development/module_deployments/week_1_deploy.sh`


## A CAUTIONARY NOTE

DO NOT run these after they have been released, they will overwrite the students work. It is important to be aware of this. Students
are encouraged to keep a backup of their progress for this reason.
